## The Pantheon — Flagship Projects

### 🌊 [P.O.S.E.I.D.O.N.](https://github.com/zarzeczako/poseidon)
**Investigative Analytics & ETL**

Named for the god who sees everything the earth tries to hide. POSEIDON ingests public procurement data through Python-driven ETL and API pipelines, then applies graph modeling to surface anomalous relationships — shell patterns, repeat-award clustering, pricing outliers — that flat tabular analysis misses.

### 📨 [H.E.R.M.E.S.](https://github.com/zarzeczako/hermes)
**Business & Pricing Optimization**

The messenger of commerce, moving value across price points. Models price elasticity of demand inside a Power BI Composite Model (Import + DirectQuery), fed by a Power Query (M) pipeline reconciling retail data against competitor pricing. Advanced DAX — including `LINESTX` regression — drives dashboards built to directly inform margin decisions.

### 🦉 [A.T.H.E.N.A.](https://github.com/zarzeczako/athena)
**System Architecture**

Strategy and structural wisdom. An end-to-end analytical system in C# / .NET 8 unifying multi-source data (API, CSV, JSON) into a governed Star Schema, with ML.NET predictive scoring and DAX-driven What-If Parameters, Time Intelligence, and Dynamic RLS — a foundation solid enough to build investment decisions on.

### Other Projects

**🏋️‍♂️🏅[Wirtualny Trener Personalny](https://github.com/zarzeczako/VirtualTrainerApp)** *(TypeScript, React, MongoDB, Docker)* — my BEng Thesis, awarded with the highest academic distinction (Wyróżniona Praca Inżynierska, grade 5.0). A NoSQL-backed platform combining structured data modeling with vector-similarity and NLP for automatic classification, including a Dialogflow chatbot built from scratch. The entire system is fully containerized, ensuring a scalable architecture and seamless real-time data processing.

**🧸[Funko Arbitrage PRO Engine](https://github.com/zarzeczako/funkoproject)** *(Python, FastAPI, YOLOv8, PostgreSQL, React)* — an automated market intelligence system for real-time arbitrage detection on eBay. Uses YOLOv8 to visually identify rare Funko variants (Chase stickers), bypassing textual traps, backed by an async pipeline, ML-driven scam prevention, and SQL Window Functions for rolling profit analysis.
